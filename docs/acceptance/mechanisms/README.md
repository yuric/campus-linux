## Reproduction and data handling

The parent worker exclusively operates the named Lima guest. Narrow delegated helpers
prepare source and inspect receipts; they do not operate competing VMs. UTM remains stopped
and unchanged. No host shares or agent forwarding are configured. Keep at least 35 GiB
host free space before large downloads/builds/VM growth; do not prune unrelated workloads.
Coordinator direction 10448 separately permits short functional probes with at least 20 GiB
host free and at most 256 MiB of actual additional owned allocation. This planning guard
does not change acceptance thresholds. The final batch records its own allocation, never
attributes global free-space changes to this worker.

The environment README gives start, authenticated login, session invocation and capture
commands. The mechanism pages give exact probe commands and expected results. Run only
in the disposable guest with synthetic fixture keys/tokens; never use owner credentials.
Guest password input uses an owner-only private file through the local QMP socket after
visually confirming the password field. No password value appears in argv or receipts.
Provider account calls and paid execution are not part of these observations.

Return only allowlisted JSON/text and public pre-entry/post-dialog screenshots. Never copy
private signing keys, provider homes, raw credentials, seed ISOs, VM disks or private setup
material. Every supplied fixture key is test-only and must be removed with fixture cleanup.
Captured synthetic token strings are intentionally public test data, not credentials.

Historical failures are retained rather than rewritten into passes. In particular the
first network boot failed, the original raw Ed25519 test was not a Tauri signature, early
renderer preflights failed, and the first Claude install hit its allocation bound. A later
corrected receipt does not erase the original observation or broaden its scope.

Installer allow-rule and process receipts are session-independent observations;
historical wayland/x11 filenames cannot establish per-tuple coverage. Prompt JSON also
lacks run-bound graphical metadata. [Package evidence limits](packages.md) preserve that
gap, authenticated-version versus signed-downgrade distinction, and the source-bound
lifecycle receipt. Historical crash absence with two simultaneous settings and a short
window is not causal isolation; the [separate G4 follow-up](core-sentinel-followup.md)
retains an inconclusive positive collector control. No raw history is rewritten.
